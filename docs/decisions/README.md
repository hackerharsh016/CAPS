# Architecture Decision Records (ADRs)

This directory contains records of all significant architectural, structural, and technological decisions made for the CAPS platform.

## Format & Standards

CAPS uses a standardized ADR structure based on the Michael Nygard format and MADR (Markdown Architectural Decision Records):

- **Numbering:** 4-digit sequential prefix (e.g., `0001-record-architecture-decisions.md`).
- **Status:** `Proposed`, `Accepted`, `Superceded`, or `Deprecated`.
- **Context:** The problem or design requirement, including relevant constraints.
- **Decision:** The chosen design or architecture direction and why it was selected over alternatives.
- **Consequences:** Both positive impacts and trade-offs/obligations introduced by this decision.
